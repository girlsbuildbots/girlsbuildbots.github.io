# Coding *for good* 💚

Programmers build things that **solve problems for real users**.

Today, in every activity, we're going to keep asking:

### **Who is this for?**

---

# Algorithm Relay 🃏

In teams, write an algorithm on cards for a physical task:
- Stack three cups into a tower 🥤
- Do a 4-move dance 💃

Then another team runs it **exactly as written**.

No interpreting. No guessing. 😈

---

# What just happened? 🤔

Missing steps → the task breaks.
Wrong order → the task breaks.

**Computers do exactly what we say.**

So precision is the coder's job.

---

# Loops save work 🔁

Without a loop:
> clap, clap, clap, clap, clap, clap

With a loop:
> **repeat 6:** clap

Same result. Way less writing.

**Where are the loops hiding in real life?**
*Brushing every tooth · dealing every card*

---

# Today's three big ideas 🧰

| Idea | What it does |
|---|---|
| **Sequence** | steps in order |
| **Event** | when THIS happens, do THAT |
| **Loop** | repeat without rewriting |

Everything you build today uses these three.

---

# Build: one concept at a time 💻

In MakeCode Arcade:

1. **Sequence** — a sprite appears and walks across the screen
2. **Event** — it moves when you press the arrow keys
3. **Loop** — a star respawns *forever* after you collect it
4. **Challenge** — add a counter for how many stars you've collected

Finished early? Become a **deputy mentor** and help a neighbor! 🎓

---

# Debug Hunt 🐛

Your pair gets a **broken program**.

1. Find the bug
2. Fix it
3. Explain **what was wrong**

*Real programmers spend more time debugging than writing.*

---

# Robot moment 🤖

Our robot code uses the **exact same three ideas**:

- **Sequences** → autonomous routines
- **Events** → driver buttons
- **Loops** → checking sensors

Just in a bigger language.

---

# Closing circle 🎯

Which concept would you teach a friend first?

**Sequence · Loop · Event**
