# Code runs your day

Trace one ordinary hour:

| What happens | The code behind it |
|---|---|

---

# The four tools 🧰

| Tool | What it does | Physical demo |
|---|---|---|
| **Event** | reacts to a trigger | when the door opens → wave |
| **Conditional** | makes a decision | if I say "blue," stand up |
| **Variable** | remembers a value | a running count on the board |
| **Loop** | repeats | repeat until told to stop |

---

# Pseudocode: idea → program 📝

Let's write one line for each, together.

```
on button pressed:
    if time < best_time:
        best_time = time
```

**Pseudocode is the bridge.** Plain language, program shape.

---

# Build: Reaction-Time Tester ⚡

A real tool, not a toy — reaction time is what sports scientists measure.

1. **Event** — on button press, start the round
2. **Variable** — a timer counts up; a score stores your best
3. **Conditional** — pressed too early → "Too soon!"; new best → update
4. **Loop** — play rounds forever, tracking the record
5. **Stretch** — two-player mode with two variables

---

# All four tools. One program. ✅

Every one of you leaves with something that actually works.

# Code Review Swap 👥

Swap laptops. On a sticky note, answer:

1. **What does this program do?**
2. Point to a **conditional**. Point to a **variable**.
3. **One thing you'd improve.**

Then discuss — and make one improvement to your own.
