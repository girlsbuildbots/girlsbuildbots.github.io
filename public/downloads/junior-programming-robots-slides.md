# Quick review: what's a program?

A program = a list of instructions a computer follows **exactly**.

But real programs have superpowers:
- **Loops** — repeat steps automatically 🔁
- **Events** — react when something happens ⚡
- **Conditions** — make decisions 🤔

Today you'll use all three!

---

# Loops: Don't Repeat Yourself! 🔁

Dance routine WITHOUT a loop:
> clap, clap, spin, jump, clap, clap, spin, jump, clap, clap, spin, jump

Dance routine WITH a loop:
> **repeat 3 times:** [clap ×2, spin, jump]

Same dance. Way less writing. **Let's perform it!** 💃

---

# Events: When THIS happens, do THAT ⚡

Events make programs interactive:

| Event | Action |
|---|---|
| arrow key pressed | move the player |
| two sprites touch | collect the item |
| timer hits zero | game over |

Robots use events too: *when bump sensor pressed → turn around*

# Debugging like a pro 🐛

When your game doesn't work:
1. **Read** your blocks out loud
2. **Predict** what should happen
3. **Compare** to what actually happens
4. **Change ONE thing** and test again

Never change five things at once — you won't know which one fixed it!
