import { Card, CardGrid } from '@astrojs/starlight/components';

:::caution[Required for teams and troops using this curriculum]
If you use Girls Build Bots materials to run a workshop, please complete all three:
:::

<CardGrid>
  <Card title="1. Credit us" icon="approve-check">
    Tell your Scouts and audience that the curriculum comes from Girls Build
    Bots, and credit "Girls Build Bots" anywhere you share about the event.
  </Card>

  <Card title="2. Tag us" icon="comment">
    Post about your workshop and tag
    [**@girlsbuildbots**](https://www.instagram.com/girlsbuildbots/) on
    Instagram.
  </Card>

  <Card title="3. Report your results" icon="email">
    Email [**girlsbuildbots@gmail.com**](mailto:girlsbuildbots@gmail.com) with:
    the number of girls who participated, the number of badges earned, and a
    sentence or two of feedback on how it went.
  </Card>
</CardGrid>

This is how the program grows and how we measure our impact — your report
becomes part of the Girls Build Bots story and helps the next troop and team.

:::note
The same ask is printed at the bottom of every lesson plan and every slide deck,
so it travels with the materials wherever they go.
:::
