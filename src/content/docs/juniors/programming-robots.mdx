## About this badge

At the Junior level, this badge moves from single commands to real programming structures. When she's earned it, a Junior can build a program using sequences, loops, and events — and explain how the same logic drives real robots.

**Scouts will learn:**

- Loops — repeat steps without rewriting them
- Events — when THIS happens, do THAT
- Conditions — programs that make decisions
- Pseudocode — planning robot behavior on paper like a roboticist

:::note[Official requirements]
The step-by-step requirements for the Junior Programming Robots badge are
published by Girl Scouts of the USA. Troop leaders access them free in the
[Volunteer Toolkit](https://mygs.girlscouts.org), or purchase the badge and requirement pamphlet
from the [Girl Scout Shop](https://www.girlscoutshop.com/badges-program/all-badges-pins/stem). Free sample activities for many
badges are on the [Girl Scout Activity Zone](https://www.girlscouts.org/en/activities-for-girls.html).

*Always verify workshop activities against the official steps before awarding the badge.*
:::

## Meeting plan

<p class="meeting-chips">
  <Badge text="⏱ 2 hours" variant="tip" size="medium" />
  <Badge text="👥 1 mentor : 4–5 Scouts" variant="tip" size="medium" />
  <Badge text="💻 MakeCode Arcade — free" variant="tip" size="medium" />
</p>

- Loop Dance warm-up — rewrite a routine with a repeat (15 min)
- Build the Battery Chase game in MakeCode Arcade — events, loops, win condition, enemy challenge (60 min)
- Program Like a Roboticist — map the game to a real robot and write pseudocode (30 min)

**Materials:** Laptops with MakeCode Arcade, projector for live coding, unplugged loop cards. Optional: micro:bit boards or a drivable robot.

## Completion checklist

By the end of the session, each Scout:

- [ ] Can explain sequences, loops, and events with an example
- [ ] Built a working game with events, a loop, and a win condition
- [ ] Wrote pseudocode for a robot behavior
- [ ] Debugged at least one problem in her own program
