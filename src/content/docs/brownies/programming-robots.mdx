## About this badge

This badge is about understanding what a program is — a clear list of steps — and creating a program a robot could run. When she's earned it, a Brownie can explain how people tell robots what to do and has written a simple program herself.

### The through-line: programming *for girls*

Brownies program a robot to solve a simple problem and help others. The focus is on learning through experimentation: plan before programming, test before improving, and use code to make a robot come to life.

**Vocabulary:** robot, program, sensor, command, sequence, engineer, prototype, input, output, coding, debugging, variable, conditional, loop, event

:::note[Official requirements]
The step-by-step requirements for the Brownie Programming Robots badge are
published by Girl Scouts of the USA. Troop leaders access them free in the
[Volunteer Toolkit](https://mygs.girlscouts.org), or purchase the badge and requirement pamphlet
from the [Girl Scout Shop](https://www.girlscoutshop.com/badges-program/all-badges-pins/stem). Free sample activities for many
badges are on the [Girl Scout Activity Zone](https://www.girlscouts.org/en/activities-for-girls.html).

*Always verify workshop activities against the official steps before awarding the badge.*
:::

### Materials

1. Printed control loop diagrams & writing utensils
2 .Painter's tape, paper markers, or small objects to create a course

*Then, pick one option:*
  1. FLL robots and their programming software, or something similar *OR:*
  2. Computer or tablet with MakeCode or Scratch *OR:*
  3. Paper, markers, tape, cups, cardboard, or other simple materials

### Activity 1 — Intro to Control Loop (15 min)

Introduce the sense → think → act control loop. Explain that a robot receives information through sensors or other inputs, processes that information using its code, and acts in response. 

Ask Scouts to consider a robot approaching an obstacle. What does it sense? What condition does its program check? What action should follow? Have Scouts trace steps using the printed control loop handout.

### Activity 2 — Programming Challenge (30 min)

Divide Scouts and give each team a challenge: program a robot or simulation to navigate a course, respond to an input, or stop before a point. Teams must identify where they use a variable, conditional, loop, and event. They should be able to explain what each one does!

Guide Scouts in whichever option you choose:
1. FLL robots: Program the robot to travel a set distance, stop or turn based on a sensor reading, or respond to a button or other supported input. Encourage Scouts to adjust their program gradually

2. MakeCode or Scratch: Create a sprite or simulated robot that moves, responds to keyboard input, detects a boundary, and changes behavior. Use variables to track a score, distance, or number of attempts; use loops and conditionals to control behavior

3. Physical materials: Write pseudocode or draw a flowchart for a robot that follows a route or responds to an obstacle. Use cups or cardboard to create a course and have a teammate execute the instructions exactly as written

### Activity 3 — Read and Debug (25 min)

Have each team exchange projects with another team. Ask Scouts to explain the other team's program. Each team should:
1. Predict the program's behavior
2. Run or simulate it
3. Identify a difference between the expected and actual results
4. Change one part of the program
5. Test again and record the result

### Activity 4 — Reflection & Conclusion (20 min)

Have each team demonstrate one behavior and explain its control loop. Ask Scouts to describe one bug, the evidence that helped them find it, and the change they made.

## Completion checklist

By the end of the session, to earn the badge, each Scout can:

- [ ] Can explain that a program is a list of steps a robot follows
- [ ] Gave clear step-by-step commands to a "human robot"
- [ ] Built and debugged a simple program
- [ ] Created and ran a simple program
