## About this badge

At the Cadette level, this badge digs into how robots are actually programmed: the sense→think→act control loop, conditionals, and variables. When she's earned it, a Cadette has programmed fully autonomous behavior — no keyboard, no driving.

**Scouts will learn:**

- The control loop: a program running forever, connected to the physical world
- Events, loops, conditionals, and variables — the core toolkit
- The Autonomy Challenge: collecting every package with zero human input
- Code review — reading a peer's code the way professional teams do

:::note[Official requirements]
The step-by-step requirements for the Cadette Programming Robots badge are
published by Girl Scouts of the USA. Troop leaders access them free in the
[Volunteer Toolkit](https://mygs.girlscouts.org), or purchase the badge and requirement pamphlet
from the [Girl Scout Shop](https://www.girlscoutshop.com/badges-program/all-badges-pins/stem). Free sample activities for many
badges are on the [Girl Scout Activity Zone](https://www.girlscouts.org/en/activities-for-girls.html).

*Always verify workshop activities against the official steps before awarding the badge.*
:::

## Meeting plan

<p class="meeting-chips">
  <Badge text="⏱ 2 hours" variant="tip" size="medium" />

- Trace the control loop on a real robot (20 min)
- Build the Autonomous Warehouse Robot in MakeCode Arcade, ending in the no-input autonomy challenge (60 min)
- Code Review Pairs — swap laptops, review, improve (30 min)

**Materials:** Laptops with MakeCode Arcade, control-loop diagram, projector. Optional: micro:bit boards, any programmable robot for demos.

## Completion checklist

By the end of the session, each Scout:

- [ ] Can explain the sense→think→act loop with a real example
- [ ] Built a program using events, loops, conditionals, and a variable
- [ ] Completed the no-input autonomy challenge
- [ ] Read a peer's code and gave constructive feedback
